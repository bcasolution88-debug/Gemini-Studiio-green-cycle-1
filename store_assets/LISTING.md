## 完整说明（4000 字符内）

**绿循环 Green Cycle —— 让每一份资源都循环起来**

绿循环是一款绿色回收循环经济平台 APP。足不出户，一键预约，回收员上门称重即结算；每一次回收都能获得碳积分，兑换环保好物、咖啡券，甚至为地球种下一棵树。

**🌿 用户端**
- 一键预约：纸类、塑料、金属、旧衣物、电子产品、玻璃、大家电、书籍，8 大品类随心选，拖动滑块预估重量，实时显示预估金额与积分
- 实时定位：回收员接单后可在地图上查看实时位置与距离，状态变更即时推送通知
- 碳积分体系：回收得积分，签到有奖励，等级越高权益越多
- 积分商城：环保帆布袋、竹纤维牙刷、咖啡券、绿植盆栽、公益植树……用积分换好物
- 减碳报告：累计减碳量、植树当量、月度趋势、品类分布，环保贡献看得见
- 环保成就：8 枚徽章记录你的绿色足迹
- 环保资讯：垃圾分类知识、环保科普、平台动态、回收员故事

**🛵 回收员端**
- 接单大厅实时抢单，一键导航到用户地址，位置共享让用户安心等待
- 现场称重按品类录入实际重量，自动结算回收款与积分
- 钱包管理：每单服务费自动入账，随时申请提现，收益明细一目了然

**🛠 平台管理后台**
- 数据概览、订单指派、用户管理、品类调价、商品与资讯运营
- 提现审核、回收员实时分布地图、一键导出 CSV 报表

**♻️ 为什么选择绿循环？**
- 透明：价格公开、称重可见、结算即时
- 便捷：预约 2 小时内上门，无需出门
- 有价值：回收不只是处理垃圾，更是为地球减碳、为自己赚积分

立即下载绿循环，开启你的绿色生活！

## 数据安全表单（Data safety）填写要点

| 数据类型 | 是否收集 | 是否共享 | 用途 | 可否删除 |
|---|---|---|---|---|
| 个人信息 → 姓名（昵称）、电话号码 | 收集 | 否 | 账号管理、应用功能 | 是（注销账号） |
| 个人信息 → 地址 | 收集 | 与接单回收员共享（履约必需） | 应用功能 | 是 |
| 位置 → 大致/精确位置 | 收集（仅回收员端、用户主动开启） | 与下单用户共享（展示距离） | 应用功能 | 是 |
| 财务信息 → 购买记录（积分兑换）、其他（提现收款账户） | 收集 | 否 | 应用功能、账号管理 | 匿名保留（审计） |
| 应用活动 → 应用内互动（订单/签到） | 收集 | 否 | 应用功能、分析 | 匿名保留 |
| 设备 ID → 推送 token | 收集 | 若启用 FCM 则经 Google 传输 | 通知 | 是 |

- 数据传输加密：**是**（HTTPS）
- 提供删除请求方式：**是**（应用内 + 网页说明）
- 不面向儿童；不包含广告；不出售数据
